## New build

Install packages 'blogdown' and 'pagedown'.

options(blogdown.server.timeout = 1200) may be necessary to allow more time to build the site

Make sure the 'git' command is available to the system.
To create the CV, the 'chromium' web-browser is required by *./R/build.R*.
